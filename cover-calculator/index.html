How we worked it out

We used the exact rules from Amazon's own KDP help pages. Here they are, so you can check us.

  1. Spine width is your page count times a number for your paper: white paper x 0.002252", cream paper x 0.0025", standard color x 0.002252", premium color x 0.002347". Source: Create a Paperback Cover, KDP help.
  2. Full cover width = bleed + back cover width + spine width + front cover width + bleed. Full cover height = bleed + trim height + bleed. Source: Create a Paperback Cover.
  3. Bleed is 0.125" (3.2 mm) on the top, bottom and outside edges. Source: Create a Paperback Cover.
  4. Spine text: "We only print spine text on books with more than 79 pages," with at least 0.0625" (1.6 mm) between the text and each spine edge. Source: Create a Paperback Cover.
  5. Safe zone: keep text at least 0.125" (3.2 mm) inside the trim lines, and keep front and back text off the spine. Borders need at least 0.25" (6.4 mm) inside the trim line. Source: Create a Paperback Cover.
  6. Barcode: the suggested size is 2" x 1.2" (50.8 x 30.5 mm). Amazon's calculator keeps it 0.25" from the edges. Source: Barcodes and the KDP Cover Calculator.
  7. Pixels: covers need at least 300 DPI, so pixels are inches times 300, rounded up to a whole pixel. Source: Create a Paperback Cover.
  8. Trim sizes and page limits come from the table on Paperback Submission Guidelines. Custom sizes (4" to 8.5" wide, 6" to 11.69" tall) come from Print Options.

We tested this page against 19 answers from Amazon's own KDP Cover Calculator, covering every standard trim size and all four papers, on November 4, 2026. Every one matched to within a thousandth of an inch. Amazon's previewer still has the final word, so please look at your cover there before you publish.
